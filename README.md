# WPM阅读测速

一个为英语阅读训练设计的极简 WPM 工具。

它不是一次性测速页，而是一个更像产品的阅读表现面板：强调趋势、轮次差异、历史记录、主题体验和离线使用。

## 为什么这个工具不一样

很多 WPM 工具只回答一个问题：这次有多快。

这个项目更在意另外三个问题：

- 最近是不是在持续变快
- 不同轮次之间差距有多大
- 用户是否愿意长期打开它、持续记录

所以它的重点不是堆表单，而是把训练结果放到界面的核心位置。

## 核心亮点

### 结果优先，不是输入优先

页面第一视觉区就是趋势图和关键数据，而不是一堆输入框。打开后先看到结果，再开始记录。

### 轮次独立统计

支持多轮阅读记录，默认从 `第一轮 / 第二轮 / 第三轮` 开始，并可扩展到最多 `第六轮`。每一轮的趋势图、平均值和历史记录都分开统计。

### 自动识别词数

粘贴英文文本后自动识别词数，并尽量排除标点和常见特殊符号。像 `don't`、`long-term` 这类词会尽量按一个词处理。

### 双时间录入方式

- 手动输入分钟 / 秒数
- 自动计时开始 / 暂停 / 重置

系统会自动计算 WPM，减少手动换算。

### 真正可长期使用的历史系统

- 删除单条记录
- 撤销最近一次删除
- 清空历史
- 回收站恢复
- 回收站清空
- JSON 导出 / 导入

### 有完整主题系统

- 亮色 / 暗色模式
- 8 种克制的高级感主题色

主题会统一作用到卡片、趋势图、状态和整体界面氛围，而不只是换一个按钮颜色。

### 可安装为离线版

项目已支持 PWA，可安装到桌面或主屏。打开一次后即可离线使用，并保留当前设备上的本地记录。

### 已安装用户可收到更新提示

检测到新版本后，会出现轻量更新提示。用户点击即可切换到最新版本，避免长期停留在旧缓存。

## 使用方式

### 1. 粘贴阅读内容

把英文文本粘贴到 `Text` 区域。

### 2. 选择轮次

默认有前三轮，也可以继续新增到第六轮。

### 3. 输入时间

你可以：

- 手动填写分钟和秒数
- 或直接使用自动计时

### 4. 保存记录

保存后页面会自动更新：

- 当前轮次趋势图
- 最近 7 次平均 WPM
- 本轮记录数
- 历史记录列表

## 首次打开

首次打开时会自动带一组示例数据，用来展示趋势图和完整界面效果。

如果你要开始记录自己的数据，只需要：

- 删除示例记录
- 或直接清空历史

之后页面就会完全按自己的数据使用。

## 数据保存说明

当前版本使用浏览器 `localStorage` 保存数据。

优点：

- 刷新不会丢
- 关闭浏览器后通常仍保留
- 安装成离线版后也能继续使用

限制：

- 不自动跨设备同步
- 不自动跨浏览器同步
- 清除站点数据后会丢失

如果需要迁移或备份，请使用导出 / 导入功能。
