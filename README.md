# WPM阅读测速

一个面向英语阅读训练的极简 WPM 工具。

它不是只给出一个速度数字的临时计算器，而是一个更像产品的阅读表现面板：支持按 `第一遍 / 第二遍 / 第三遍` 分开记录，自动识别词数、计算 WPM、展示趋势，并可安装为离线版使用。

## 项目预览

- 结果优先布局：先看趋势，再看数据，再录入内容
- 自动识别词数：尽量排除标点与特殊符号
- 多轮次独立统计：第一遍、第二遍、第三遍互不混淆
- 历史记录管理：删除、撤销、清空、回收站恢复
- 主题系统：亮色 / 暗色 + 8 种高级感配色
- PWA 支持：可安装、可离线使用

## 为什么这个工具值得用

大多数 WPM 工具的问题，不是不能算速度，而是只能算一次速度。

真正有价值的是：

- 你最近有没有变快
- 同一篇材料在不同轮次之间差异有多大
- 你的阅读表现是在稳定上升，还是偶尔波动

这个项目的重点，是把“训练结果”放到界面的核心位置，让用户打开页面先看到趋势和表现，再进行输入。

## 核心功能

### 1. 自动识别词数

粘贴英文文本后，系统会自动识别词数，并尽量排除：

- 标点符号
- 连续空格
- 常见特殊符号

像 `don't`、`long-term` 这类词会尽量按 1 个词处理。

### 2. 自动计算 WPM

支持两种时间录入方式：

- 手动输入分钟 / 秒数
- 自动计时开始 / 暂停 / 重置

系统会根据词数和时间自动计算 WPM，无需手动换算。

### 3. 三轮次独立记录

支持：

- 第一遍
- 第二遍
- 第三遍

每个轮次的趋势图、最近 7 次平均 WPM、历史记录都会独立统计。

### 4. 趋势与结果面板

页面会优先展示：

- 当前轮次 WPM 趋势图
- 最近 7 次平均 WPM
- 本轮记录数
- 当前轮次状态

更适合持续训练，而不是只看单次结果。

### 5. 历史记录与回收站

支持：

- 删除单条记录
- 撤销最近一次删除
- 清空历史
- 回收站恢复
- 回收站清空

误删记录不会立刻丢失，方便找回。

### 6. 导入 / 导出备份

支持导出 JSON，用于：

- 本地备份
- 跨设备迁移
- 分享测试数据

导入后会自动合并记录，尽量避免重复写入。

### 7. 主题系统

支持亮色 / 暗色模式，以及 8 种主题风格：

- 赤
- 橙
- 黄
- 绿
- 青
- 蓝
- 紫
- 石墨

主题不只是按钮换色，还会影响整体界面氛围、卡片、趋势图和状态层级。

### 8. 可安装离线版

项目已支持 PWA。

在支持的浏览器中，用户可以直接安装为离线版，之后像本地工具一样打开和使用。

## 使用方式

### 快速开始

1. 打开页面
2. 粘贴英文阅读内容
3. 选择轮次
4. 输入时间，或使用自动计时
5. 保存记录
6. 查看趋势图和历史结果

### 首次打开

首次打开时，页面会自动带一组示例记录，用于展示完整趋势和界面效果。

如果想开始记录自己的数据，只需要：

- 删除示例记录
- 或直接清空历史

之后页面就会完全按自己的数据使用。

## 数据保存说明

当前版本使用浏览器 `localStorage` 保存数据。

这意味着：

- 刷新页面不会丢
- 关闭浏览器后通常也还在
- 安装成离线版后也能继续使用

同时也意味着：

- 不会自动跨浏览器同步
- 不会自动跨设备同步
- 清除站点数据后会丢失

如果需要迁移或备份，请使用导出 / 导入功能。

## 技术实现

这是一个纯前端静态项目，没有后端依赖。

主要文件：

- [index.html](./index.html)
- [styles.css](./styles.css)
- [script.js](./script.js)
- [manifest.json](./manifest.json)
- [sw.js](./sw.js)

技术特点：

- 原生 HTML / CSS / JavaScript
- CSS 变量驱动的主题系统
- `localStorage` 本地持久化
- `service worker` 离线缓存
- PWA 安装支持

## 本地运行

因为项目包含 `service worker`，更推荐通过静态服务器启动，而不是直接双击 `index.html`。

例如：

```bash
npx serve .
```

或使用任意静态服务器工具。

## 适合谁

这个工具适合：

- 想训练英语阅读速度的人
- 想比较三轮阅读差异的人
- 想保留历史趋势的人
- 想使用本地轻量工具的人
- 想把工具安装到桌面或主屏的人
