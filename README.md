## 产品定位

大多数 WPM 工具只是一个测速器。  
这个项目更像一个阅读训练面板。

它解决的不是“这一次有多快”，而是这些更长期的问题：

- 最近是不是在持续变快
- 不同轮次之间差距有多大
- 同一轮次的表现是否稳定
- 用户是否愿意长期打开并持续记录

所以它的设计重点不是表单，而是结果、节奏和长期使用感。

## 产品特点

### 1. 结果优先的首页结构

打开页面先看到趋势图和关键数据，而不是输入框。  
首页首先回答的是“你现在的表现如何”，而不是“你要填什么”。

### 2. 多轮次独立统计

默认支持 `第一轮 / 第二轮 / 第三轮`，并可继续扩展到最多 `第六轮`。  
每一轮都有独立的：

- 趋势图
- 最近 7 次平均 WPM
- 本轮记录数
- 历史记录

### 3. 自动识别词数

粘贴英文文本后，系统会自动识别词数，并尽量排除标点与常见特殊符号。  
像 `don't`、`long-term` 这类词会尽量按一个词处理，降低手动录入误差。

### 4. 双时间模式

- 手动输入分钟 / 秒数
- 自动计时开始 / 暂停 / 重置

两种方式都直接服务于同一条记录流程，不会拆成两套割裂体验。

### 5. 完整的历史记录系统

不是只记一次结果，而是提供完整记录管理能力：

- 删除单条记录
- 撤销最近一次删除
- 清空历史
- 回收站恢复
- 回收站清空
- JSON 导出 / 导入

### 6. 有完整审美体系的主题界面

支持：

- 亮色 / 暗色模式
- 8 种克制的高级感主题色

主题会同步影响卡片、趋势图、状态和整体氛围，而不是只改一个按钮颜色。

### 7. 可安装、可离线、可更新

项目已支持 PWA：

- 可安装到桌面或主屏
- 可离线继续使用
- 已安装用户可收到新版本更新提示

这让它更像一个真正的个人工具，而不是一次性网页。

## 适合谁

- 想训练英语阅读速度的人
- 想比较不同轮次表现的人
- 想保留长期趋势的人
- 想使用本地轻量工具的人
- 想把工具安装到桌面或主屏的人

## 使用方式

### 第一步：粘贴阅读内容

把英文文本粘贴到 `Text` 区域。

### 第二步：选择轮次

默认前三轮可直接使用，也可以继续新增轮次。

### 第三步：输入时间

你可以：

- 手动填写分钟和秒数
- 或直接使用自动计时

### 第四步：保存记录

保存后页面会自动更新：

- 当前轮次趋势图
- 最近 7 次平均 WPM
- 本轮记录数
- 历史记录

## 首次使用

首次打开时会自动带一组示例数据，用来展示趋势图和完整界面效果。  
如果要开始记录自己的数据，只需要删除示例记录，或直接清空历史。

## 数据保存

当前版本使用浏览器 `localStorage` 保存数据。

优点：

- 刷新不会丢
- 关闭浏览器后通常仍保留
- 安装成离线版后也能继续使用

限制：

- 不自动跨设备同步
- 不自动跨浏览器同步
- 清除站点数据后会丢失

如果需要迁移，请使用导出 / 导入功能。

## 离线安装

1. 打开网页
2. 进入右上角设置
3. 点击 `安装离线版`

安装后可以：

- 像本地应用一样打开
- 离线继续使用
- 保留当前设备上的本地记录

如果已经安装，检测到新版本后会出现轻量更新提示，点击即可刷新到最新版。

## 技术实现

这是一个纯前端静态项目，没有后端依赖。

- 原生 HTML / CSS / JavaScript
- CSS 变量驱动主题系统
- `localStorage` 本地持久化
- `service worker` 离线缓存
- PWA 安装与更新提示

主要文件：

- [index.html](./index.html)
- [styles.css](./styles.css)
- [script.js](./script.js)
- [manifest.json](./manifest.json)
- [sw.js](./sw.js)

## 本地运行

因为项目包含 `service worker`，建议通过静态服务器运行，而不是直接双击 `index.html`。

```bash
npx serve .
```
